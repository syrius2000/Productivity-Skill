# writing-great-skills 利用案内

## 使う場面

Agent Skillの本文、metadata、参照ファイル、起動境界を設計・レビュー・改善したいときに使います。予測可能な実行手順、情報の置き場所、重複した指示の整理を検討します。

## 期待できる価値

各指示が実際の行動を変えるかを点検し、必要な完了条件や安全制約を残したまま、重複・古い記述・読まれない情報を見つけます。短くすること自体を目的にしません。

## 使わない場面

通常のコードレビュー、Skillと無関係な文章校正、承認済みの実装作業そのものには使いません。実装の前提や変更範囲を決める場合は、必要に応じて計画レビューを先に行います。

## 明示起動

`/writing-great-skills <対象と目的>` と入力して起動します。これは明示起動専用のスキルです。

## 最初に渡す情報

- 対象Skillのパスと、直したい利用者の困りごと
- 期待する行動と、現在起きている望ましくない挙動
- 保持すべき承認、安全、データ、互換性の制約

## 評価時の注意

改善は本文の短さではなく、同じ入力に対して必要な制約を守り、具体的な変更理由と完了条件を示せるかで評価します。本文を変更する場合は、既存の検証と承認範囲を確認します。

## 例

`/writing-great-skills 本番更新を禁止する規則が複数箇所に重複しているSkillを整理したい。失敗時は停止して利用者へ報告する制約を必ず残したい。`

用語と詳細な設計原則は [SKILL.md](SKILL.md) と [GLOSSARY.md](GLOSSARY.md) を参照してください。
