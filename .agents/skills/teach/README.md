# teach 利用案内

## 使う場面

複数回にわたり、技術・概念・コードの理解を深めたいときに使います。学習の目的、既存の理解、前回までの学習記録を基に、次の説明と演習を調整します。

## 期待できる価値

学習の目的に結び付いた短い教材、演習、振り返りを継続して扱えます。単に説明を読むだけでは理解済みと扱わず、回答や演習で示された理解を次回の出発点にします。

## 使わない場面

一問だけの質問、既存コードの調査・説明、教材や記録を残さない短い回答には使いません。その場合は通常の対話、または対象に合うコード理解スキルを使います。

## 明示起動

`/teach <学びたいこと>` と入力して起動します。これは明示起動専用のスキルです。

## 最初に渡す情報

- 学びたい目的と、実務や学習で使う場面
- 現在の知識、困っている点、以前に試したこと
- 教材・学習記録を残すかどうか

## 保存規則

教材、参照資料、学習記録、ポータルは `docs/learning/` に保存します。作成前には既存の同ディレクトリを確認し、作成・更新するファイルの計画を示して確認を得ます。既存の教材、`MISSION.md`、`NOTES.md` は上書きしません。

## 例

`/teach JOINで二重計上が起きる理由を、売上集計の例で体系的に学びたい。SQLの基本的なJOINは分かる。演習と学習記録を残したい。`

詳細な実行規則は [SKILL.md](SKILL.md) を参照してください。
