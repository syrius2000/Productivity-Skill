## 目的と変更対象

英語本文を保持して価値を検証し、日本語の短い利用案内を作る。Teachの価値は学習履歴に応じた次回の指導、writing-great-skillsの価値は具体的な設計判断の改善である。英語であること、他者由来であることだけで採否を決めない。

変更対象は、各ディレクトリに新設する日本語 `README.md`、ルート `README.md` の該当2件の案内、`docs/Artifacts/` の評価結果。SKILL.md、GLOSSARY.md、各FORMAT文書、agents/openai.yamlはこの段階では読取りのみ。日本語案内は入口と評価上の注意を簡潔に示し、英語本文の第二の正本にしない。

本文の誤動作や保存契約を直す必要が見つかった場合は、症状・修正箇所・方式・検証を本計画へ追記して再承認する。本文改修を日本語案内に隠して実施しない。

## 実装仕様

この段階で編集する本文は、日本語の入口だけである。`teach/SKILL.md`、teachの4つのFORMAT文書、`writing-great-skills/SKILL.md`、`GLOSSARY.md`、両方の`agents/openai.yaml`は変更禁止とする。

| 新規ファイル | 見出しと固定内容 |
|---|---|
| `.agents/skills/teach/README.md` | `# teach 利用案内`、`## 使う場面`（複数回にわたる理解支援）、`## 使わない場面`（単発の質問・既存コード説明）、`## 明示起動`（`/teach <学びたいこと>`）、`## 最初に渡す情報`（目的、現在の知識、成果物を残すか）、`## 保存規則`（教材は `docs/learning/` に保存し、同ディレクトリに既存教材がある場合は上書きしない）、`## 例`（JOINの二重計上を学びたい） |
| `.agents/skills/writing-great-skills/README.md` | `# writing-great-skills 利用案内`、`## 使う場面`（Skill本文・metadata・参照の設計レビュー）、`## 使わない場面`（通常のコードレビュー・無関係な文章校正）、`## 明示起動`（`/writing-great-skills <対象と目的>`）、`## 最初に渡す情報`（対象パス、困っている挙動、保持すべき制約）、`## 評価時の注意`（短文化ではなく行動変化を評価）、`## 例`（重複する承認規則の整理） |
| `README.md` | 既存のteach・writing-great-skillsの説明直後へ各READMEへの相対リンクを1行ずつ追加する。起動方法、ライセンス、本文の意味を重複記載しない |

E5とE6を用いた価値評価は、本文変更の効果測定ではなく「明示起動を維持する価値の判断」である。比較できない場合の結論は「継続価値は静的確認のみ」であって「廃止」ではない。日本語READMEがあることは、英語本文の品質向上の証拠にしない。

## 評価上の重要条件

| 対象 | 必須確認 | 採否の考え方 |
|---|---|---|
| Teach | 両群で同じ履歴にアクセス可能。閲覧を理解と誤認しない。既存ノートを保持 | 次の説明・演習が理解状況に適応し、継続利用の負担に見合えば継続候補 |
| Teach | 指導内容の比較と、保存・再開の実動作を分ける | 擬似履歴による比較だけなら実際の長期学習効果は未確認 |
| writing-great-skills | 採点基準は事前に固定した共通基準。短文化の比率を点数にしない | 必要な制約を残しつつ、具体的な設計改善が増えるなら継続候補 |
| 日本語案内 | 説明を読んだ人が用途・起動・入力を選べる | 案内改善とLLM本文性能を別の成果として報告 |

結論は「継続利用」「用途を限定して継続」「現行維持・効果未確認」「統合候補」「廃止候補」から根拠に即して選ぶ。入力中の証拠と出力の該当箇所を対照表に残す。廃止候補でも実ファイルは削除しない。

## 検証

利用案内の相対リンク、説明とfrontmatterの一致、英語本文と補助ファイルの不変を確認する。依存の追加やコードテストは原則不要。READMEのインベントリに影響する場合だけ、既存 `tests/test_skill_inventory_contract.py` を読み、副作用確認後に関連する確認を実施する。比較モデルと独立コンテキストが使えなければ静的な継続価値の仮説までとする。

## してはならないこと

- 英語本文の全面翻訳、再構成、自動起動化、無承認のルーター追加をすること。
- Teachに有利な履歴を追加する、模擬回答を実際の学習改善の証拠にすること。
- Teach教材を `docs/learning/` 以外に保存すること、または既存教材を上書きすること。
- 既存教材・MISSION・NOTESを上書き・移動する、ブラウザを自動起動すること。
- 除外4スキルをwriting-great-skillsの改修教材にすること。
- writing-great-skillsの短文化原則で承認・安全・統計的制約を消すこと。
- 日本語案内へ大量の独自規則を追加し、本文の欠陥を直したことにすること。
- ライセンス表示の新設・書換え、配布、削除、コミット、pushをすること。
